# Virtu System® — Site Institucional

Repositório estático preparado para Cloudflare Pages.

## Publicação
1. Crie um repositório no GitHub.
2. Envie todo o conteúdo desta pasta.
3. No Cloudflare: Workers & Pages → Create application → Pages → conecte o repositório.
4. Framework: nenhum.
5. Build command: deixar vazio.
6. Output directory: `/` (raiz).
7. O Cloudflare fornecerá um endereço `*.pages.dev`.
8. Depois, um domínio próprio poderá ser conectado.

## Estrutura
- `index.html` — página inicial
- `pages/` — páginas institucionais
- `css/style.css` — identidade visual e responsividade
- `js/main.js` — navegação
- `assets/` — ativos da marca
- `manual/` — materiais institucionais
